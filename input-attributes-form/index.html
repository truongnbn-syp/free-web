Co-browsing - input属性の確認（#7598 機能要件 1-3）

このページをホスト側のブラウザで開き、このタブを画面操作共有してください。拡張機能: 確認中…

A. キーボードの種類（type / inputmode / enterkeyhint）

ゲスト端末（iPhone / iPad / Android）で各項目をタップし、表示されるキーボードを確認してください。

B. ゲスト側の入力制御（maxlength / minlength / placeholder）

C. ホストブラウザによる検証（ゲスト側にメッセージ表示）

ゲストが入力してから約0.5〜1秒後に、ホストブラウザの検証メッセージがゲスト側の入力欄の下に表示されること。メッセージの言語はホストブラウザの言語に従う。

D. ホスト画面のイベント（input / change / keydown / iframe）

残り 30 文字（最大30文字、ページのJSで計算）
changeイベント回数: 0（入力中は増えず、ゲストが確定したときのみ増える）
ホストのキーボードでは数字以外を入力できない。ゲストからの入力はブロックされない想定（対応範囲外）。

E. リグレッション確認（select）

input（青）/ change（黄）/ keydown（赤）/ click（緑）。パスワードの値はマスク表示。
